Six for six in the same direction on a paired, discordant-only comparison is not the shape of noise,
and it is consistent with the measured round trip: CLOB read p50 44 ms / p90 79 ms, so a quote needs
~89 ms minimum and D=300 is the only arm near what the box can actually do. BUT the unpaired sweep
does NOT agree: m0.15 is monotone in D, m0.20 is not (-0.0713, -0.1708, -0.1564, -0.1298), and a
non-monotone sweep peaking at an arbitrary cell is exactly what this project treats as noise. So the
honest statement is that speed helps on the trades where speed is the only difference, and that this
is not yet enough to make the rule positive at any D.
