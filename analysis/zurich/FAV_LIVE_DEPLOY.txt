THE DEFECT WAS MINE. A gate already existed for build11 and my fav/fav_mid deploy did not extend it.

path in _decide_once. So with ef_engine="fav_mid" BOTH could send live orders, and on 09-30 03:00:56
the v10 path sent one: sec 56 (outside FAV's 60-180), cheap side at 0.39, -$9.9995 - 79% of that

THE DIFF (smallest possible: the gate's engine list, plus the predicate extracted so it is testable)
  -            if self.ef_engine()=='build11':
  -                d=dict(d,fire=False,reason='EF engine build11 (lane) - v10 shadow: '+...)
  +            _efe=self.ef_engine()
  +            if self._v10_order_blocked(_efe):
  +                d=dict(d,fire=False,reason=f'EF engine {_efe} (lane) - v10 shadow: '+...)
