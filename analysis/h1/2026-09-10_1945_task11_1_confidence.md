# H1 — Task 11.1: confidence score from the engine's own features

**Result: it does not work, and this RETRACTS the "+33% per unit" recommendation I made repeatedly
today and which V wrote into Task 11. The score has no predictive power on the v11 twins.**

## The test

378 twin fires carrying the 34-field `ef_v11_f` engine feature dict joined to their ask and outcome
(twin B 169, twin C 172, twin E 37), 19.5 h span. Standardised L2 logistic, walk-forward in both
directions (fit h1 → score h2, fit h2 → score h1), so every fire's P(win) is out of sample.

**OOS AUC = 0.4746** — below random — and consistently so: 0.4813 scoring h2, 0.4800 scoring h1.

Per twin, with no cross-twin candle leakage possible:

| twin C | 172 | 34 | 0.5386 | 0.5511 | 0.5302 |
| poly_pnl runner (the Task 8 set) | 305 | 35 | 0.5644 | 0.5837 | 0.5486 |

## Why my Task 8 number did not survive

Task 8 measured engine-feature sizing on the **v10 runner** and got AUC ~0.56 and +33% per unit. Run
identically here the runner still gives 0.5644 and +0.157 vs +0.119 flat — that number was real for
that engine. **It simply does not transfer to the v11 twins** (0.479, 0.539). One engine's feature
set carried a little signal over one 41-hour window; the other's does not.

I over-sold it. I called it "the follow-on with real upside" and "a bigger effect than anything the
path model produced" in four separate messages to V. The first proper test of it fails. **Do not
build the v12 confidence score on this.**

## What this means for Task 11 as a whole

11.1 is closed negative. That leaves **11.2 (retrain the forecaster)** and **11.3 (later second
entry)** as the live lines — and they are the right ones, because they change the *model*, not the
threshold on an existing weak score.

The constraint they have to beat, now measured three ways: the path does not beat the ask; path
features added to engine features make things worse; and the engine features alone carry no usable
ranking on the v11 path. **A better model over the same inputs is not going to work.** The next real
gain has to come from information the book does not already have.

## Caveats

378 fires over 19.5 h; twins share candles so the pooled figure is not 378 independent observations —
which is why the per-twin table is the one to read. Twin A's `ef_v11_f` is empty in the snapshot, so
it could not be included. Feature dicts differ slightly between the v10 runner (35 fields) and the
v11 twins (34), so the two are not a like-for-like model comparison, only a like-for-like procedure.
